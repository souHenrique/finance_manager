# Sistema de Gestão Financeira Pessoal
## Visão Geral
O Sistema de Gestão Financeira Pessoal é uma API REST desenvolvida do zero para controle e consolidação de receitas, despesas, cartões de crédito. Este projeto serve como um caso de estudo aplicado em engenharia de software e arquitetura backend, implementando regras de negócio transacionais, auditoria de dados e práticas limpas de modelagem.
